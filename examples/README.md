# Examples

Walkthrough examples demonstrating the Lavanda Code framework.

## Available Examples

### [Contact Form Feature](./showcase/contact-form-example.md)

A complete end-to-end example of building a simple contact form feature.

**What you'll see:**
- Step 1: `clarify` - Transform vague idea into specific requirements
- Step 2: `challenge` - Stress-test decisions with hard questions
- Step 3: `define` - Create a full PRD with user stories
- Step 4: `roadmap` - Break into phased vertical slices
- Step 5: `tickets` - Create grabbable GitHub issues

**Duration:** ~15 minutes to read through

**Concepts demonstrated:**
- Idea → Clarified → Challenged → PRD → Plan → Tickets → Implementation

---

## How to Use These Examples

1. **Read the showcase** to understand the flow
2. **Try it yourself** with your own feature idea
3. **Follow the workflow** in your project

### Quick Start

```
1. Load clarify skill → Refine your idea
2. Load challenge skill → Stress-test it
3. Load define skill → Write PRD
4. Load roadmap skill → Create plan
5. Load tickets skill → Create issues
```

Then for each phase:
```
builder → research → implement → verify → review → test → audit → deploy
```
