# Skill Registry

## Planning
- `grill-me` - Stress-test ideas through relentless interview
- `write-a-prd` - Create PRD through interview and codebase exploration
- `prd-to-plan` - Break PRD into phased vertical slices
- `prd-to-issues` - Convert plan into GitHub issues
- `idea-refiner` - Clarify vague requirements

## Precision
- `research-first` - Read and search before writing code
- `verification-loop` - Verify output against plan criteria

## Implementation
- `orchestrator` - Manager, coordinates work
- `project-scaffold` - Initialize new projects
- `frontend-injector` - UI, pages, components
- `api-developer` - Backend APIs
- `database-specialist` - Schemas, queries
- `auth-implementation` - Authentication
- `devops-deployer` - CI/CD, deployments

## Quality
- `code-reviewer` - Code quality
- `engine-tester` - Tests
- `security-auditor` - Security

## Flow

```
grill-me → write-a-prd → prd-to-plan → [per phase: research-first → build → verification-loop] → deploy
```
