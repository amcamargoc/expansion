# Skill Registry

## Discovery
- `idea-refiner` - Clarify vague requirements
- `project-scaffold` - Initialize new projects

## Implementation
- `orchestrator` - Manager, coordinates work
- `frontend-injector` - UI, pages, components
- `api-developer` - Backend APIs
- `database-specialist` - Schemas, queries
- `auth-implementation` - Authentication
- `devops-deployer` - CI/CD, deployments

## Quality
- `code-reviewer` - Code quality
- `engine-tester` - Tests
- `security-auditor` - Security

## Flow

```
idea-refiner → project-scaffold → orchestrator → [implementation] → [quality] → deploy
```
